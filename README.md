# OW META TIER // オーバーウォッチ メタティアリスト統合ハブ

オーバーウォッチ（Overwatch）の最新パッチ環境における**プロ・上位配信者のヒーローティアリスト**と**高レート帯（GM/マスター）の公式・Overbuff統計データ**を自動収集・統合し、真の「メタ」を可視化するWebプラットフォームです。

---

## 🌟 主な機能

- **TierMaker風 メタティアリスト表示**:
  - おなじみのS/A/B/C/Dカラースタイルと正方形グリッドによる直感的なティア表。
  - 公式Blizzard CDNの高解像度ヒーローサムネイル画像を採用。
  - SNS共有用PNG画像エクスポート機能・共有リンクコピー機能。
- **詳細データカード & テーブル表示**:
  - メタスコア、GM勝率、ピック率、配信者評価内訳でのソート・フィルタリング。
- **個別ヒーロー詳細モーダル**:
  - 各プロ・ストリーマーの個別所見・評価理由。
  - 有利/不利マッチアップ（カウンター・相性）および味方シナジー情報。
  - パッチノート変更履歴。
- **AI画像解析 PoC (Gemini 2.0 Flash Vision)**:
  - 配信者・プロがSNSやYouTubeサムネイルで公開したTierMaker画像をマルチモーダルAIが画像スキャンし、各行のヒーローを自動抽出・JSON構造化してメタスコアに即時加算。
- **ベイズ推定メタスコア集計エンジン**:
  - プロ合意スコア（$S_{pro}$）と統計実績スコア（$S_{stat}$）の加重合成。
  - サンプル数不足による勝率ブレを低減するベイズ平滑化モデルを搭載。
  - 比率調整スライダー（パッチ直後 75:25 〜 データ重視 40:60）でリアルタイムシミュレーション可能。

---

## 🛠 技術スタック

- **フロントエンド**: React 18, TypeScript, Vite
- **スタイリング**: Vanilla CSS（CSS Tokens, グラスモーフィズム, レスポンシブ対応）
- **アイコン**: Lucide React
- **画像アセット**: Blizzard Entertainment 公式 CloudFront CDN
- **データ解析 PoC**: Python 3, Gemini Flash Vision API, Overbuff / 公式Leaderboard Crawler

---

## 🚀 ローカル起動方法

```bash
# 依存パッケージのインストール
npm install

# 開発サーバー起動
npm run dev
```

ブラウザで `http://localhost:5173/` にアクセスします。

---

## 📦 本番ビルド

```bash
npm run build
```

`dist/` ディレクトリに静的アセットが出力されます。Vercel, Cloudflare Pages, Netlify等にそのままデプロイ可能です。
